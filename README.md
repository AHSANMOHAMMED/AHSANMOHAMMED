## 🛵 Doorli — Local Commerce & Operations Platform

<div align="center">

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github)](https://github.com/AHSANMOHAMMED/Doorli)
[![Stars](https://img.shields.io/github/stars/AHSANMOHAMMED/Doorli?style=for-the-badge&color=FFD700)](https://github.com/AHSANMOHAMMED/Doorli)
[![Forks](https://img.shields.io/github/forks/AHSANMOHAMMED/Doorli?style=for-the-badge&color=06b6d4)](https://github.com/AHSANMOHAMMED/Doorli)
[![Issues](https://img.shields.io/github/issues/AHSANMOHAMMED/Doorli?style=for-the-badge&color=F4845F)](https://github.com/AHSANMOHAMMED/Doorli)

</div>

**Doorli** is a multi-role local commerce and operations ecosystem connecting **customers, vendors, drivers, and platform operators** — bringing marketplace shopping, food & grocery, services, courier, mobility, payments, and community features into a unified platform.

<details>
<summary><b>🏗️ Platform Modules</b></summary>
<br/>

| Module | Description |
|--------|-------------|
| 🛍️ Local Marketplace | Product discovery & vendor storefronts |
| 🍔 Food & Grocery | Ordering, menus & delivery |
| 📦 Order Management | End-to-end order lifecycle |
| 🚚 Delivery Operations | Driver workflows & tracking |
| 🚕 Mobility & Rides | Transportation services |
| 🛠️ Service Bookings | Book local professionals |
| 🏨 Hotels, Halls & Events | Venue & event management |
| 🛒 Cart & Checkout | Multi-vendor cart, LKR payments |
| 💳 Wallets & Payments | Digital wallet & transaction system |
| 🎁 Loyalty & Promotions | Rewards, coupons & engagement |
| 💬 Community & Notifications | Real-time communication |
| 🤖 AI-Assisted Experiences | Smart recommendations & search |
| 🏢 Embedded ERP | Business operations & analytics |
| 📱 Mobile Applications | Cross-platform mobile apps |

</details>

<sub>

**Engineering:** Full-stack architecture · Multi-role authorization · PostgreSQL/PostGIS · Docker · Mobile · CI/CD · Cloud deployment

</sub>
